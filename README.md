# 教學－GitHub Pages 網頁公開

[開啟教學網站](https://erichuang-kcislk.github.io/my-first-page/)

給已經做好 HTML 網頁、想把網址分享出去的同仁。跟著 7 個步驟，從學校 Google 帳號登入，到上傳檔案與公開網頁。保留 9 張操作截圖及 3 段可複製的 AI 指令，需要時再展開閱讀。

`index.html` 是網站首頁，`圖片` 資料夾存放教材截圖。教學內容以 `把HTML公開到GitHubPages_新手教學.md` 為來源，由 `製作教學網頁.mjs` 產生 HTML；修改內容時，更新來源後重新產生首頁。
